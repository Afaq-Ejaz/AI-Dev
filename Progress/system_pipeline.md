# TicketWise — Detailed Learning Objectives

## Core Concept
TicketWise intentionally spans several areas of software engineering and AI engineering. The goal is to see how these isolated technologies interact in one functioning application, creating a realistic engineering workflow.

## Skill Domains

### 1. Python (Core Engineering)
*   Structuring functions, classes, and modules.
*   Data structures and typing.
*   Error handling and tracebacks.
*   JSON parsing and application organization.
*   NumPy operations.

### 2. Data Modeling (Pydantic)
*   Creating schemas and structured data.
*   Defining strict validation rules and constraints (e.g., constrained categories).
*   Enforcing input/output boundaries.
*   Serialization (converting memory objects to JSON).

### 3. API Engineering (FastAPI)
*   HTTP protocols and REST APIs.
*   Building endpoints (`POST /triage`).
*   Handling request bodies and response models.
*   Status codes, error handling, and ASGI concepts.

### 4. LLM Engineering (Google GenAI)
*   Model integration and precise prompting.
*   Forcing structured outputs.
*   Classification, reasoning fields, and tracking confidence scores.
*   Controlling LLM behavior so it behaves predictably.

### 5. Embeddings & Vector Retrieval
*   Understanding text representation as high-dimensional vectors.
*   Vector dimensionality and semantic relationships.
*   Dot products, vector norms, and cosine similarity.
*   Ranking and top-match retrieval (understanding what vector databases actually do under the hood).

### 6. AI Application Architecture
*   Learning how a reliable system is built by combining: 
    *Validation + Language Understanding + Structured Data + Retrieval + Deterministic Logic + Error Handling.*
